2) ทดสอบทุก LAB 0–9 ตามลำดับในการทดลองเดียว (container ทดลอง 1 ตัว publish SSH port ว่างตามสกิล เพื่อทดสอบ ssh -L ด้วย) รันคำสั่งเหมือนที่นักศึกษาจะพิมพ์ ให้ไฟล์อยู่ใน /workspace/002_kubernetes_pod/02_LAB ใน container เก็บ output จริงของทุกคำสั่งสำคัญไว้ที่ /root/workspace/DevTools/k/logs/002_pod/lab-run/labNN.log (ไฟล์ละ LAB, มีคำสั่ง + output) เพื่อใช้เขียน README ต่อ ให้ยืนยันข้อที่แผนยังเดาไว้: ค่า READY ของ som-shop (2/2 หรือไม่), ลำดับ STATUS ตอน init, วิธีหยุด db ที่ได้ผลจริง, เวอร์ชันจริงของ postgres/Next.js, ข้อความ Events จริงของ CrashLoopBackOff/ImagePullBackOff/OOMKilled/FailedScheduling/Liveness probe failed

   - ทดสอบสั่งซื้อผ่าน POST /api/orders แล้ว stock ลด, restart db แล้วข้อมูลยังอยู่, ลบ Pod แล้ว apply ใหม่ข้อมูลกลับเป็นค่าเริ่มต้น
