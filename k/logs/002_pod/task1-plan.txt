- LAB สุดท้าย: deploy เว็บขายอาหารแมว "ร้านอาหารแมวน้องส้ม" ด้วย Next.js + PostgreSQL ที่เป็น container โดยออกแบบให้อยู่ใน **Pod เดียวแบบ multi-container** (Next.js คุย Postgres ผ่าน localhost:5432 เพราะยังไม่เรียน Service) มี init container รอ DB พร้อม, emptyDir เป็นที่เก็บข้อมูล DB (สอนว่าข้อมูลรอด container restart แต่หายเมื่อลบ Pod), build image แล้ว kind load docker-image เข้าคลัสเตอร์, เปิดดูด้วย port-forward + ssh -L ระบุในแผนว่าเป็นการออกแบบเพื่อการเรียนรู้ บทหน้าจะแยกด้วย Deployment/Service
