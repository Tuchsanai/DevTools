สิ่งที่ต้องทำ:
1) สร้าง manifest ของ LAB ทั้งหมดตามแผน มีคอมเมนต์ภาษาไทยสั้น ๆ อธิบาย field สำคัญสำหรับมือใหม่ LAB สุดท้ายคัดลอกแอปจาก /root/workspace/DevTools/k/002_kubernetes_pod/02_LAB/som-shop/app มาไว้ในโฟลเดอร์ของบทนี้ตามแผน (ไม่ต้องคัดลอก node_modules/.next) เพื่อให้บทนี้ใช้งานได้ด้วยตัวเอง
2) ทดสอบทุก LAB ตามลำดับเหมือนนักศึกษาพิมพ์ (cd /workspace/003_kubernetes_node_pod/02_LAB) เก็บคำสั่ง+output จริงที่ /root/workspace/DevTools/k/logs/003_node_pod/lab-run/labNN.log ยืนยันทุกจุดใน "จุดที่ต้องยืนยันตอนทดสอบจริง" ของแผน และจับเวลาจริง (NotReady หลัง docker stop กี่วินาที, eviction ตาม tolerationSeconds, เวลาที่ node กลับ Ready หลัง docker start, nodeTaintsPolicy Ignore vs Honor ให้ผลจริงอย่างไร, ข้อความ Events/คำเตือนจริงของ drain, FailedScheduling แต่ละแบบ) ถ้าผลจริงต่างจากแผน ให้ปรับ LAB ให้ถูกต้องและบันทึก
   - หลัง LAB ที่ทำให้ node ล่ม ต้องยืนยันว่า node กลับ Ready ก่อนทำ LAB ถัดไป ถ้าไม่กลับให้ใช้แผนสำรองและบันทึกเป็นคำแนะนำสำหรับนักศึกษา
   - LAB สุดท้าย: ทดสอบ port-forward 2 สาขา + ssh -L จากเครื่องนี้ (ผ่าน gateway + askpass ตามสกิล) curl หน้าเว็บทั้งสองสาขาเห็นชื่อสาขาเป็นชื่อ node จริง, สั่งซื้อผ่าน POST /api/orders แยกสาขา, drain/node ล่มตามแผน
3) **ห้ามลบ container ทดลองหลังจบ** ให้รีเซ็ต LAB สุดท้ายกลับสู่สภาพ "2 สาขาเปิดอยู่คนละ node ทั้งสองรันปกติ, ทุก node Ready/uncordon" และเปิด port-forward ทั้งสองสาขา (--address 127.0.0.1, port 3001 และ 3002 ใน container, รันด้วย setsid nohup) เพื่อให้ผู้ประสานงานถ่าย screenshot เขียนข้อมูลการเข้าถึงลง /root/workspace/DevTools/k/logs/003_node_pod/lab-run/handoff.md (ชื่อ container, ssh host port, gateway, คำสั่งเปิด tunnel, คำสั่งที่จะใช้จำลอง drain/ล่มสำหรับ screenshot ถ้าต้องการ) ผู้ประสานงานจะลบ container เอง
4) เขียนสรุปที่ /root/workspace/DevTools/k/logs/003_node_pod/lab-run/SUMMARY.md: ผ่าน/ไม่ผ่านรายข้อ, ค่าเวลาจริง, ข้อความจริงที่สำคัญ, การเปลี่ยนแปลงจากแผน, ป้าย/ข้อความในภาพ storyboard ที่ไม่ตรงผลจริง (เทียบกับ /root/workspace/DevTools/k/logs/003_node_pod/images.json ส่วน "Text (verbatim" ของ T20, L01–L22) พร้อมค่าที่ควรใช้แทน, ข้อควรระวังสำหรับนักศึกษา
