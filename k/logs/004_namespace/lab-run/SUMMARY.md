## ข้อควรระวังสำหรับนักศึกษา (ใส่ใน README)

- ต้อง build **`som-shop-web:1.1`** ใหม่จาก `som-shop-envs/app` (1.0 ของบท 002/003 ไม่มี eyebrow/footer จาก env — ร้านยังรันได้แต่ footer เป็น "LAB 002") และ load postgres ด้วย `docker save --platform linux/amd64` + `kind load image-archive` (ARM ใช้ linux/arm64 ไม่ได้ทดสอบ)
- **ลืมคืน namespace ของ context** (LAB2) แล้วคำสั่งถัดไปจะไปผิดโซน — ตรวจด้วย `kubectl config get-contexts` (คอลัมน์ NAMESPACE)
- ไฟล์ที่มี `metadata.namespace` แล้วสั่ง `-n` ไม่ตรง = error; ไฟล์ที่ใช้หลาย env ไม่ควรใส่ `metadata.namespace`
- `kubectl get all` ไม่รวม ConfigMap/ServiceAccount/Role/RoleBinding/Quota — ต้องระบุชนิดเอง
- `kubectl delete ns` ลบทุกอย่างข้างใน ไม่มีถังขยะ; `kube-node-lease` ระบบ **ไม่กัน** การลบ (default/kube-system/kube-public กัน) — ห้ามลอง
- ชื่อ namespace ขึ้นต้น `kube-` สร้างได้ แต่ห้ามใช้ (สงวนให้ระบบ)
- NetworkPolicy มีผลทันที (ภายในคำสั่งถัดไป); `wget -T 3` จะรอ 3 วิแล้ว `download timed out`
- `kubectl --token=...` บน kubeconfig ของ kind **ยังเป็น admin** — ต้องสร้าง user/context ใหม่; อย่าลืม `kubectl config delete-context ...` / `delete-user intern` ตอนเก็บกวาด และ token จาก `create token` ใช้ไม่ได้หลังลบ SA/namespace (`Unauthorized`)
- PSA ตรวจเฉพาะตอนสร้าง Pod — เปลี่ยน label เป็น restricted แล้ว Pod เดิมยังรัน (มีแต่ Warning); ใช้ `kubectl label --dry-run=server` ตรวจก่อน
- image ที่ `USER` เป็นชื่อ (node) ต้องใส่ `runAsUser` เป็นตัวเลข ไม่งั้น `CreateContainerConfigError` "non-numeric user"
- ข้อความ quota ระบุทุกค่าที่เกินในบรรทัดเดียว (สาขาที่ 3 เกิน 4 ค่า) — LimitRange ตรวจก่อน quota
- port-forward ผูกกับ Pod: หลังลบ som-dev หน้า 3001 ใช้ไม่ได้ และ process port-forward จบตอนมีคนเข้าครั้งถัดไป (`error: lost connection to pod`); เปิด 3 ตัวใน terminal เดียวใช้ `&` แล้วเก็บกวาดด้วย `pkill -f "[k]ubectl port-forward"` (pattern แบบ `[k]` กันไปฆ่า shell ตัวเอง — การทดสอบนี้เผลอฆ่า shell ตัวเองอีกครั้งด้วย `pkill -f "[s]sh -f -N ... -L 13001"` เพราะ command line ของ shell มีข้อความ `ssh -f -N ... -L 13001` จริง)
- ssh -L 3 port ในคำสั่งเดียว: `ssh -p 2223 -L 3001:localhost:3001 -L 3002:localhost:3002 -L 3003:localhost:3003 root@localhost`
- รหัส DB `meow1234` ใน YAML เพื่อการเรียนเท่านั้น
