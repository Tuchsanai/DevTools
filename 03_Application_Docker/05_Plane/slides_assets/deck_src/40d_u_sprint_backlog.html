Sprint Backlog — Why · What · How ของ Sprint เดียว

แผนซึ่ง Developers เป็นเจ้าของ และเป็นภาพ real-time ว่าจะทำอะไรใน Sprint นี้เพื่อให้บรรลุ Sprint Goal
อ่านกล่องกลาง — Sprint Backlog = งานที่เลือก + งานย่อยใต้แต่ละใบ + commitment คือ Sprint Goal (ภาพเลือก 4 เรื่อง รวม 19 pts ให้พอกับ velocity ≈ 20)
นิยาม — Sprint Backlog ประกอบด้วย Sprint Goal (why) · PBI ที่เลือกมาทำใน Sprint นี้ (what) · แผนลงมือที่ทำให้เกิด Increment (how) เป็นแผน “โดยและเพื่อ Developers”— Scrum Guide 2020

ทำไมสำคัญ · ปัญหาที่แก้

ก่อน: ต่างคนต่างหยิบงาน จบรอบได้ของครึ่ง ๆ กลาง ๆ ไม่มีผลลัพธ์ร่วม · หลัง: เป้าหมายเดียว ขอบเขตสั้น และแผนซึ่งตรวจความคืบหน้าได้ทุกวันใน Daily Scrum

ส่วนประกอบ · workflow

Sprint Planning: ตั้ง Sprint Goal → เลือก PBI กับ PO ให้พอกับกำลังทีม → แตกงานย่อย ≤ 1 วัน · ระหว่าง Sprint ปรับแผนได้ตลอด และนับเฉพาะงานที่ผ่าน DoD เข้า Increment

ตัวอย่างจริง · CampusEats LAB 4

Goal “นักศึกษาค้นหาร้าน ดูเมนู ใส่ตะกร้า และสั่งอาหารได้ครบวงจร” → PBI-01…05 + 09 + 10 = 7 ใบ · 3+2+3+5+3+2+1 = 19 points ในงบ ≤ 20 · PBI-06…08 (5+8+8) ใหญ่เกินจึงยังรอใน Product Backlog

ความเข้าใจผิด — ❌ “เลือกเข้า Sprint แล้วห้ามแตะจนจบ” → ✅ Developers ปรับแผนได้ทุกวันและเจรจาขอบเขตกับ PO ได้ ตราบใดที่ไม่ทำลาย Sprint Goal · ❌ “Sprint Backlog = รายการงาน” → ✅ ถ้าไม่มี Goal และแผน ก็เป็นแค่ to-do list

ใน Plane — work items ที่อยู่ใน Cycle คือ Sprint Backlog

สมาชิกของ Cycle เก็บในตาราง cycle_issues — การเพิ่มงานเดิมเข้า Cycle คือการผูกความสัมพันธ์ ไม่ใช่การก๊อปปี้ใบงาน
ภาพจริง · LAB 4 — Plane Lab › Cycles › Sprint 1 (ยัง 0 work item) เปิดโมดัลเลือกงานเดิม: ชิปด้านบนคือ 7 ใบที่ติ๊กไว้ (PLAB-1…5, 9, 10 = PBI-01…05, 09, 10) รวม 19 points ก่อนกด Add selected work items

Menu pathเพิ่มงานเดิมเข้า Cycle

Plane Lab › Cycles › Sprint 1: Cycle ว่าง → Add existing work item · มีงานแล้ว → + หัวกลุ่ม List/Board → Add an existing work item

ฟิลด์ · ตาราง · endpoint

cycle_issues unique cycle+issue · POST …/cycles/<id>/cycle-issues/ · ใบที่อยู่ Cycle อื่นจะถูก ย้าย โดยแก้ cycle_id แถวเดิม — “1 ใบ 1 cycle” เป็น logic ของ view ไม่ใช่ constraint ของ DB

ฟีเจอร์ที่เกี่ยวข้อง · Cycle description

Cycle มีแค่ name · description · start_date/end_date — ไม่มีฟิลด์ Sprint Goal LAB 4 จึงเขียน Goal, บทบาท และ DoD ไว้ใน description (แสดงในแผงขวาของหน้า Cycle)

CE limit · Plane v1.4.2 — โปรเจกต์ใหม่ปิด Cycles ไว้ (cycle_view=False): เปิดที่ Project settings › Features › Cycles › Enable cycles ไม่เช่นนั้น API v1 ตอบ “Cycles are not enabled for this project” · Cycle ที่เลย end_date แล้วเพิ่มงานไม่ได้ (400 CYCLE_COMPLETED)
LAB 4Mini exercise — เหลือ PBI-01 ค้นหาร้าน (3) · PBI-02 ดูเมนู (2) · PBI-03 ตะกร้า (3) · PBI-04 สั่งอาหาร (5) งบ Sprint = 10 points: เลือกชุดที่รวมไม่เกินงบและยังส่งผลลัพธ์ที่ผู้ใช้ใช้ได้จริง 1 อย่าง เขียน Sprint Goal 1 ประโยค และบอกว่าใบที่เหลือไปอยู่ที่ใด
