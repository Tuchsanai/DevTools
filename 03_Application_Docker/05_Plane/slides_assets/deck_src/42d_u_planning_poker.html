Planning Poker — เปิดไพ่พร้อมกัน เพื่อเปิดเหตุผลที่ต่างกัน

วิธีประมาณขนาดงานร่วมกัน: เลือกไพ่เป็นความลับ → เปิดพร้อมกัน → อภิปรายค่าที่ต่าง → เลือกใหม่จนได้ค่าที่ใช้วางแผนได้
“คะแนนที่ต่างกันคือสัญญาณให้ทีมค้นหาสมมติฐานและงานแฝงร่วมกัน”

ทำไมจึงสำคัญ

ถ้าคนแรกพูด “5 points” คนถัดไปมักขยับตามโดยไม่รู้ตัว เรียกว่า anchoring; การเลือกไพ่ลับทำให้ทุกมุมมองเริ่มต้นมีน้ำหนักเท่ากัน

ปัญหาที่แก้

ก่อน: ประเมินโดยคนเสียงดังหรือหัวหน้าคนเดียว งานแฝงจึงไม่ถูกพูดถึง · หลัง: ค่าที่ต่างมากบังคับให้ทีมเปิดเผยสมมติฐาน ความเสี่ยง และงานที่ลืม

ความเข้าใจผิดที่พบบ่อย — ❌ เฉลี่ยเลขหรือหาเลขชนะ → ✅ คุยเหตุผลที่ต่างจนเข้าใจขอบเขตตรงกัน แล้วเลือกค่าที่ดีพอสำหรับวางแผน
ไพ่แต่ละใบแทนขนาดสัมพัทธ์ของงาน ไม่ใช่จำนวนชั่วโมงหรือกำหนดส่ง
