ตอนที่ 2 · นิยาม · APPLICATION · TOOL · PLATFORM

Application · Tool · Platform และทางเลือก SaaS กับ self-hosted

Application

ซอฟต์แวร์ที่ผู้ใช้ปลายทางเปิดใช้เพื่อทำงานหนึ่งอย่างจนจบ มี UI มีข้อมูลของตัวเอง เช่น Plane, Jira, Trello

Tool

โปรแกรมทำงานเฉพาะจุด มักเรียกจากบรรทัดคำสั่งหรือถูกโปรแกรมอื่นเรียก เช่น git, docker, curl, jq

Platform

ฐานที่ให้แอปและ tool อื่นมาต่อยอดผ่าน API และส่วนขยาย เช่น GitHub, Kubernetes — Plane ก็กลายเป็น platform เมื่อเราใช้ API และ webhook ของมัน

ประเด็นSaaS (ผู้ให้บริการรันให้)Self-hosted (เรารันเอง เช่น Plane ใน LAB)
ความเป็นเจ้าของข้อมูลข้อมูลอยู่บนเซิร์ฟเวอร์ผู้ให้บริการ ย้ายออกได้เท่าที่เขาให้ exportข้อมูลอยู่ใน Postgres และ MinIO ใน volume ของเราเอง สำรองและย้ายได้ทั้งก้อน
ต้นทุนค่าใช้จ่ายรายหัวต่อเดือน ไม่ต้องดูแลเครื่องค่าเครื่องและเวลาคนดูแล: อัปเกรด สำรองข้อมูล แก้ปัญหาเอง
การควบคุมตั้งค่าได้เท่าที่ผู้ให้บริการเปิดให้ปรับ env ทุกค่า ปิด telemetry ต่อ SMTP และ OAuth (Google / GitHub / GitLab / Gitea) ได้
Licenseตามสัญญาบริการ (Terms of Service)ตาม open-source license — Plane ใช้ AGPL-3.0: ใช้และแก้ได้ฟรี แต่ถ้าให้บริการรุ่นที่แก้ผ่านเครือข่ายต้องเปิดซอร์สส่วนที่แก้
ในวิชานี้เลือก self-hosted — เพื่อให้เห็นทุกชั้นของแอปตั้งแต่ proxy ถึงฐานข้อมูล ข้อแลกเปลี่ยนคือเราต้องเป็นผู้ดูแลระบบเอง ซึ่งเป็นทักษะที่ต้องการฝึกอยู่แล้ว

ตอนที่ 2 · SINGLE SOURCE OF TRUTH

Single source of truth — แอป PM คือศูนย์กลางของ toolchain

ข้อมูลสถานะงานต้องมีแหล่งเดียว เครื่องมืออื่นทั้งหมดส่งเหตุการณ์เข้ามาหรือดึงข้อมูลออกไปจากแหล่งนั้น
เหตุการณ์จาก toolchain ไหลเข้าแหล่งเดียว และรายงานทุกแบบคำนวณจากข้อมูลชุดเดียวกัน

Single source of truth

ทุกคนดูสถานะงานจากที่เดียว ไม่ต้องถามในแชตหรือเปิดสเปรดชีตหลายไฟล์ เมื่อมีสองแหล่ง ข้อมูลจะขัดกันเสมอและไม่มีใครรู้ว่าอันไหนจริง

แอป PM เป็น hub

work item เชื่อมกับ commit และ pull request, ผล CI, error จาก monitoring และเอกสาร รายงานอย่าง burndown และ analytics จึงคำนวณจากข้อมูลจริง ไม่ใช่จากที่ใครจำได้

กาวที่เชื่อม = API · webhook · import/export

แอปอื่น "push" เหตุการณ์เข้ามาผ่าน API หรือรับแจ้งผ่าน webhook และเรา "pull" ข้อมูลออกไปวิเคราะห์ด้วย export — Plane มีครบทั้งสาม (สไลด์จุดต่อขยาย)
