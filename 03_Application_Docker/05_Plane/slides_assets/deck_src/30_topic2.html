ตอนที่ 2 · SDLC · ขั้นตอนและงานในแต่ละขั้น

ทุกขั้นของ SDLC มีแอปพลิเคชันช่วยเสมอ

วงจรพัฒนาซอฟต์แวร์แบ่งเป็นขั้น แต่ละขั้นมีงานเฉพาะ และมีเครื่องมือประเภทหนึ่งเกิดขึ้นมารองรับงานนั้น
  • Requirementsเก็บ user story จัดลำดับ backlog — Plane, Jira
  • Designโมเดล ERD ADR wireframe — draw.io, Excalidraw, Figma
  • Implementationเขียนโค้ด review ควบคุมเวอร์ชัน — VS Code, Git, GitHub
  • Testingunit / integration / e2e รันอัตโนมัติใน CI — pytest, Playwright
  • Deploymentbuild image ปล่อยรุ่น ตั้งค่า environment — Docker, Compose, Kubernetes
  • Operations / Maintenancelog metrics incident support และ feedback กลับสู่ backlog — Grafana, Sentry, Plane
ข้อสังเกต — งานติดตาม (tracking) ไม่ได้อยู่แค่ขั้นเดียว work item เกิดที่ Requirements และปิดที่ Operations / Maintenance แอปพลิเคชันด้าน PM จึงเป็นเส้นด้ายที่ร้อยทั้งวงจรไว้ด้วยกัน
