CFD — ประวัติการไหลของงานทั้งระบบในภาพเดียว

แกนนอน = เวลา · แกนตั้ง = จำนวนงานสะสม · ความหนาของแต่ละแถบ = จำนวนงานในสถานะนั้น ณ เวลานั้น
Cumulative Flow Diagram (CFD) คือกราฟพื้นที่ซ้อนที่แสดงจำนวนงานสะสมซึ่งผ่านแต่ละขั้นของ workflow ตามเวลา โดยพื้นที่ระหว่างเส้นสองเส้นคือจำนวนงานที่อยู่ในขั้นนั้น ณ เวลานั้น

ปัญหา → หลังใช้ · เห็นแนวโน้ม

ก่อน: บอร์ดบอกเพียงว่าวันนี้งานอยู่คอลัมน์ใด จึงไม่รู้ว่าคิว Review บวมนานเท่าไร · หลัง: CFD เก็บรูปทรงข้ามวัน ทำให้เห็นคิวที่ยาวขึ้นและช่วงที่ระบบติดขัด

ทำไมสำคัญ · 4 สัญญาณร่วมกัน

CFD ช่วยอ่าน WIP จากความหนาแนวตั้ง · lead time โดยประมาณ จากช่องว่างแนวนอน · throughput จากความชัน Done · และ คอขวด จากแถบกลางที่กว้างขึ้น

CampusEats · เห็นคิวก่อนส่งช้า

ทีมรับคำขอช่วงเปิดเทอมเร็วกว่าที่ review และ deploy ได้ แถบ In Progress จึงอ้วนขึ้น แม้ทุกคนดูยุ่ง CFD ชี้ว่าควรหยุดดึงงานใหม่ แล้วช่วยกันระบายปลายน้ำ

ความเข้าใจผิดที่พบบ่อย — ❌ “CFD คือภาพสถานะของบอร์ดวันนี้” → ✅ CFD ต้องมี snapshot หลายวันจึงเห็นแนวโน้ม · ❌ “เส้นบนสูงขึ้นแปลว่าแย่” → ✅ เส้นบนคือ scope สะสม; ต้องอ่าน ความหนาและความชันของแต่ละแถบ ร่วมกัน

อ่าน CFD จาก เส้นขอบ · ความหนา · ช่องว่าง · ความชัน

นับจำนวนงานปลายแต่ละวันแล้วซ้อนเป็นแถบ · ช่องว่างแนวนอนเป็นเพียงค่า lead time โดยประมาณ ไม่ใช่เวลาของงานใบใดใบหนึ่ง

กลไก · สร้างกราฟ 3 ขั้น

1) นับงานในแต่ละสถานะ ณ สิ้นวัน 2) บวกเป็นเส้นสะสมตามลำดับ workflow 3) ระบายพื้นที่ระหว่างเส้น แล้วเปรียบเทียบรูปทรงข้ามวัน

องค์ประกอบ · เส้นขอบและแถบ

เส้นบนสุด = scope ที่เข้าระบบสะสม · เส้นขอบ Done = output สะสม · พื้นที่ระหว่างเส้นติดกัน = จำนวนงานในสถานะนั้น; จึงอ่าน WIP จากความหนาแนวตั้ง

Workflow การอ่าน · ตามรูปทรง

อ่านแนวตั้งหา WIP → แนวนอนหา lead time โดยประมาณ → ดูความชัน Done หา throughput → หาแถบกลางที่กว้างขึ้นเพื่อระบุคอขวด

จากกราฟสู่การตัดสินใจ — เมื่อแถบ In Progress กว้างขึ้นต่อเนื่อง อย่าเร่ง “เริ่ม” เพิ่ม: หยุดดึงงาน · ช่วยขั้นปลายน้ำ · ตรวจ exit policy และ WIP limit แล้วดูรอบถัดไปว่าแถบกลับมาคงที่หรือไม่

Plane + ฟีเจอร์ที่เกี่ยวข้อง

Plane CE v1.4.2 ไม่มี CFD ในตัว; Analytics › Work items มี Created vs Resolved ซึ่งผูกแกนเวลากับเดือนที่สร้างและนับ resolved จากกลุ่ม completed ปัจจุบัน จึงไม่ใช่การเล่นประวัติ state
