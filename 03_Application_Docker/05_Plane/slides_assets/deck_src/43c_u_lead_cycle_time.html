ตอนที่ 3 · Lead time & Cycle time · นิยาม

งานใบเดียวกัน — ลูกค้ารอตั้งแต่ขอ ทีมวัดตั้งแต่เริ่ม

สอง metric นี้ใช้ปลายทางเดียวกัน แต่ตอบคนละคำถาม: “ผู้ขอรอนานเท่าไร?” และ “หลังทีมเริ่มแล้ว งานไหลนานเท่าไร?”

นิยาม · Lead time

เวลาที่ผ่านไปตั้งแต่รับคำขอหรือสร้าง work item จนงานเข้า Done — รวมคิวก่อนเริ่ม ตลอดจนเวลาทำและเวลารอระหว่างขั้นตอน

นิยาม · Cycle time

เวลาที่ผ่านไปตั้งแต่งานเข้าสู่ขั้นที่ทีมกำหนดว่า “เริ่มแล้ว” จนเข้า Done — ในหน่วยนี้ใช้การเข้า state กลุ่ม started ครั้งแรกเป็นจุดเริ่ม

ทำไมสำคัญ

Lead time สะท้อนประสบการณ์ของผู้ขอ จึงเป็นตัวเลขที่ใช้ตอบคำถาม “จะได้เมื่อไร”; Cycle time ช่วยทีมแยกความช้าหลังเริ่มงานออกจากเวลาที่รออยู่ใน backlog

ปัญหาที่แก้ · ก่อน

บอกเพียง “เฉลี่ย 3 วัน” จึงไม่รู้ว่างานรอก่อนเริ่ม หรือค้างใน Review/Test และงานช้ามากบางใบถูกค่าเฉลี่ยกลบ

หลังวัด

แยกเวลารอก่อนเริ่มออกจากเวลาหลังเริ่ม และรายงาน percentile เพื่อเห็นหางยาวของการกระจาย

ตัวอย่าง · CampusEats จาก LAB 5

PBI-01 ถูกสร้าง 168 ชม.ก่อน เริ่ม 156 ชม.ก่อน และ Done 120 ชม.ก่อน → Lead = 48 ชม. · Cycle = 36 ชม. · เวลารอก่อนเริ่ม = 12 ชม. (ใช้ external_id; เลข PLAB-N ต่างกันได้ในแต่ละเครื่อง)

❌ ความเข้าใจผิด

Cycle time คือชั่วโมงที่นักพัฒนาแตะคีย์บอร์ดเท่านั้น

✅ แก้ให้ถูก

เวลารอ Review, Test หรือ Deploy หลังเริ่มงานยังอยู่ใน Cycle time

ความสัมพันธ์ที่จริงเสมอ — Lead time ≥ Cycle time เพราะช่วง Cycle เป็นส่วนย่อยของช่วง Lead; ส่วนต่างคือ เวลารอในคิวก่อนเริ่ม ซึ่งย่อได้ด้วยการจำกัด WIP และจัดลำดับ backlog ให้ดีขึ้น ไม่ใช่ด้วยการเร่งคนที่กำลังเขียนโค้ด

องค์ประกอบ · สามจุดเวลา

รับคำขอ → จุดเริ่ม Lead
เข้า started ครั้งแรก → จุดเริ่ม Cycle
เข้า completed → จุดจบของทั้งคู่

กลไก · ต่อหนึ่งใบ

Lead = เสร็จ − รับคำขอ
Cycle = เสร็จ − เริ่มทำครั้งแรก
Queue = Lead − Cycle

Workflow · จากใบงานสู่ P85

คำนวณทุกใบที่ Done ด้วยขอบเขตเดียวกัน → เรียงระยะเวลาจากน้อยไปมาก → หา P50/P85; P85 คือค่าที่งานอย่างน้อย 85% เสร็จภายในนั้น จึงใช้ตอบผู้ขอได้ดีกว่าค่าเฉลี่ย

ขอบเขตต้องตรงกัน — จะเริ่มนับ Cycle ที่ “In Progress” หรือ “Ready” ก็ได้ตาม policy แต่ห้ามสลับนิยามกลางชุดข้อมูล · ความเชื่อมโยงกับ WIP และ Little’s Law อยู่ในหน่วย WIP limit ก่อนหน้านี้
