LAB 8 · 008_LAB_Webhooks_Automation · หัวข้อ 4

Automation Wall — webhook · HMAC · SSRF allowlist · rules แบบ Butler · retry · bot user

คำถามก่อนเริ่ม: ถ้า receiver ล่ม Plane จะทิ้ง event หรือส่งซ้ำ และกี่ครั้ง?
  • hookwall — receiver stdlib ใน network plane_default (ภาพ d12): ตรวจ X-Plane-Signature กับ raw body · dedup ด้วย X-Plane-Delivery · UI SSE สด
  • SSRF guard — ครั้งแรก UI ปฏิเสธ http://hookwall.lab:9000/hook: "Invalid or disallowed webhook URL" (hostname ต้องมีจุด) จนใส่ WEBHOOK_ALLOWED_HOSTS=hookwall.lab,dashboard.lab แล้ว pc up -d api worker beat-worker
  • rules.json — urgent ไม่มีเจ้าของ → comment + label · Done → ขอ demo link · /eta → ตั้ง target date · ทำโดย bot user ที่มี token ของตัวเอง (ตรวจสอบย้อนหลังได้)
  • retry — docker pause hookwall → 500 Read timed out ใน webhook_logs → celery inspect scheduled เห็น ETA (backoff 600 s + jitter, สูงสุด 5 ครั้งแล้วปิด webhook) → docker unpause hookwall
