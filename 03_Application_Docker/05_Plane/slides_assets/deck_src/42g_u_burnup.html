Burn-up — แยก “ทำเสร็จแล้ว” ออกจาก “ขอบเขตทั้งหมด”

แกนนอน = เวลา · แกนตั้ง = จำนวนงานหรือ points · ระยะห่างระหว่างสองเส้นคืองานที่ยังเหลือ
อ่านฝั่งขวา: เส้นเขียว = Done สะสม · เส้นม่วง = Scope รวม · Scope เพิ่มวันที่ 5 จึงมองเห็นเหตุของช่องว่างได้ทันที
นิยาม — Burn-up คือกราฟสองเส้น: งาน Done สะสม และ Scope รวม ณ แต่ละวัน จึงเห็นทั้งความคืบหน้าและการเปลี่ยนขอบเขตในภาพเดียว

ทำไมสำคัญ · ปัญหาที่แก้

เส้น Remaining เส้นเดียวอาจแยกไม่ออกว่าทีมเดินช้าหรือ scope เปลี่ยน; Burn-up แยกผลงานที่ Done ออกจากขอบเขต จึงคุยสาเหตุได้ตรงจุด

องค์ประกอบ · กลไกการอ่าน

ทุกวัน d บันทึก Done(d) กับ Scope(d) แล้ววาดสองเส้น; ช่องว่างคือ Remaining(d) = Scope(d) − Done(d). เส้น Done อาจลดเมื่อเปิดงานกลับหรือแก้ข้อมูล

ตัวอย่าง CampusEats · เข้าใจผิด

LAB 4: Sprint 1 เริ่ม 7 ใบ แล้วเพิ่ม action item tech-debt 1 ใบ → Scope 8; เมื่อ Done 3 จึงเหลือ 5. ❌ เส้นสูงขึ้น = แย่ · ✅ Done สูงขึ้น = คืบหน้า; Scope สูงขึ้น = ขอบเขตเพิ่ม
