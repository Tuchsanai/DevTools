# PRD — CampusEats Ordering

## Problem
นักศึกษาต้องเดินไปต่อคิวหน้าร้านในโรงอาหารช่วงพักเที่ยง ทำให้เสียเวลาเฉลี่ย 18 นาที/มื้อ และร้านค้ารับออเดอร์ผิดพลาดบ่อยเพราะจดด้วยมือ

## Goals
- นักศึกษาสั่งอาหารล่วงหน้าจากมือถือได้ภายใน 3 ขั้นตอน (ค้นหาร้าน → เลือกเมนู → ยืนยัน)
- ร้านค้าเห็นออเดอร์ทันทีและกดรับ/ปฏิเสธได้ในคลิกเดียว
- ลดเวลารอเฉลี่ยจาก 18 นาที เหลือไม่เกิน 5 นาที

## Non-goals
- ยังไม่ทำระบบจัดส่งโดยไรเดอร์ (อยู่ใน module Notifications)
- ยังไม่รองรับการชำระเงินออนไลน์ (อยู่ใน module Payments)

## User stories
- ในฐานะนักศึกษา ฉันต้องการค้นหาร้านตามชื่อ เพื่อสั่งจากร้านที่ชอบได้เร็ว
- ในฐานะนักศึกษา ฉันต้องการเห็นเมนูพร้อมราคา เพื่อตัดสินใจก่อนสั่ง
- ในฐานะร้านค้า ฉันต้องการกดรับ/ปฏิเสธออเดอร์ เพื่อแจ้งลูกค้าว่ากำลังทำ

## Metrics
- เวลารอเฉลี่ยต่อออเดอร์ (นาที) — เป้า ≤ 5
- อัตราออเดอร์ที่ร้านปฏิเสธ — เป้า < 3%
- จำนวนออเดอร์ต่อวันหลังเปิดใช้ 2 สัปดาห์ — เป้า ≥ 200
