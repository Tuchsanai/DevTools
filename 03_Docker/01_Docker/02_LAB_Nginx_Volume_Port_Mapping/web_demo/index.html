--:--:--
🔌

Port Mapping

-p 8083:80 ส่ง port 8083 ของเครื่องเรา เข้า port 80 ที่ Nginx ฟังอยู่ในกล่อง

📁

Volume Mapping

-v ${PWD}/web_demo วางโฟลเดอร์ของเราทับ web root ของ Nginx ทั้งดุ้น

🔒

Read-only :ro

กล่องอ่านไฟล์เราได้ แต่เขียนทับไม่ได้ — ลองสั่งเขียนดูจะได้ Read-only file system

คำสั่งเดียวที่ทำให้หน้านี้ขึ้นมา

docker run -d -p 8083:80 \
  -v ${PWD}/web_demo:/usr/share/nginx/html:ro \
  nginx

🧪 ลองพิสูจน์เอง — 20 วินาที

  1. แก้ไฟล์ web_demo/index.html บนเครื่องเรา (ไม่ต้องแตะ container)
  2. กด F5 ที่หน้านี้
  3. เนื้อหาเปลี่ยนทันที — ไม่ได้ restart container เลยสักครั้ง
