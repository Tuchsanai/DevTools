# แนวทางภาษาวิชาการของชุดวิชา Kubernetes (ผู้สอนกำหนด 2026-09-03: "ต้องการให้การใช้ภาษาทั้งหมดเป็นภาษาวิชาการ")

## A. หลักการ (บังคับทุกไฟล์: README ทุกระดับ · YAML_Guide.md · สไลด์ · photos.md · ข้อความในไดอะแกรม)
1. ใช้ภาษาไทยระดับทางการ/วิชาการ แบบเอกสารประกอบการสอนระดับอุดมศึกษา: ประโยคสมบูรณ์ มีประธาน-กริยา ชัดเจน ไม่ใช้ภาษาพูด ไม่ใช้คำลงท้าย ไม่ใช้คำอุทาน ไม่ใช้สแลง
2. ไม่ใช้สรรพนามบุรุษที่ 1-2 (ผม เรา คุณ) → ใช้ "ผู้เรียน" "ผู้สอน" หรือเรียบเรียงเป็นประโยคไม่ระบุบุคคล (เช่น "เมื่อลบ Pod ระบบจะสร้าง Pod ใหม่")
3. คำถามเชิงโวหาร (rhetorical) → เปลี่ยนเป็นประโยคบอกเล่า หรือคำถามทางการที่ลงท้ายด้วย "หรือไม่ / อย่างไร / เหตุใด"
4. ศัพท์เทคนิคของ Kubernetes/Docker/Linux คงเป็นภาษาอังกฤษตามเดิม (Pod, Deployment, kubectl, container, cluster, manifest, rollout ...) ไม่ถอดเสียง · คำทั่วไปใช้ภาษาไทย · ศัพท์บัญญัติที่ใช้: สภาพที่ต้องการ (desired state) · สภาพจริง (actual state) · การปรับให้สอดคล้อง (reconcile) · ป้ายกำกับ (label) · ตัวเลือก (selector) · เนมสเปซ (namespace) ใช้คำอังกฤษได้เมื่ออ้างชื่อ object
5. หน่วยเวลา/ตัวเลขเขียนแบบทางการ: "เวลา 03.00 น." ไม่ใช่ "ตีสาม" · "จำนวน 3 รายการ" ไม่ใช่ "3 ตัว"
6. ความยาวใกล้เคียงเดิม (±10% ของจำนวนบรรทัดต่อไฟล์) ไม่เพิ่มเนื้อหาใหม่ ไม่ตัดเนื้อหาเดิม — เปลี่ยน "ภาษา" เท่านั้น
7. ตัวอักษรเชิงโครงสร้างที่ linter ใช้ (📝 ✅ 💡 ❓ 🧭 และ "—" ในหัวข้อ) คงไว้ · เครื่องหมาย "?" ท้ายหัวข้อให้เลี่ยง
