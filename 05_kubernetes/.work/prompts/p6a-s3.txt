ข้อบังคับด้านเนื้อหา/สไตล์:
- ภาพสถาปัตยกรรมประจำแล็บต้องตรงกับ object ที่แล็บนั้นสร้างจริงตาม outline (namespace, Deployment/ReplicaSet/Pod, Service, Ingress, ConfigMap, Secret, PVC, เบราว์เซอร์ที่ localhost:8080 หรือ 3000) ไม่ใส่ของที่แล็บนั้นยังไม่ได้เรียน
- ภาพทฤษฎีต้อง "สอนได้ในภาพเดียว": มีชื่อภาพด้านบน ป้ายกำกับภาษาไทยสั้น ๆ (ศัพท์เทคนิคคงอังกฤษ) ลูกศรบอกทิศทาง
- สไตล์เรียบ: roughness 0, fillStyle solid, พื้นขาว, ตัวอักษร ≥ 20px (ชื่อภาพ 28-32px)
  สี: acc #1c5cab (K8s object ทั่วไป) · ok #116b11 (Service/สถานะดี) · warn #86590a (ConfigMap/Secret/Ingress) · crit #a32222 (พัง/ถูกลบ) · ink #18181b (ข้อความ)
  พื้นการ์ด: accw #eaf2fd · okw #e7f6e7 · warnw #fdf3dd · critw #fbeaea · เส้นกรอบ rule #d4d4d8
- รูปทรงของ object แต่ละชนิดต้องเหมือนกันทุกภาพ (เช่น Pod = สี่เหลี่ยมมุมมน accw · Service = สี่เหลี่ยมมุมมน okw ขอบเขียว · Ingress = กล่อง warnw · PVC = ทรงกระบอกหรือกล่องขอบหนา · node/namespace = กรอบเส้นประ · เบราว์เซอร์ = กล่องมีแถบหัว)
- ขนาดภาพราว 1200-1600 x 700-900 px จัดให้เต็มพอดี ไม่มีพื้นที่ว่างมหาศาล
- ห้ามใส่ข้อมูลจริง (email/ชื่อคน)
