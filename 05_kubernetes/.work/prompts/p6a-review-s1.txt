ขั้นที่ 1 — ตรวจทุกภาพ (ห้ามข้ามภาพใด ห้ามเดาจากไฟล์ SVG ต้องดูภาพจริง):
  render แต่ละ SVG เป็น PNG:  node /root/workspace/DevTools/05_kubernetes/.work/tools/shot.js "file://<path.svg>" /root/workspace/DevTools/05_kubernetes/.work/diagram-review-s1/<ชื่อ>.png --w 1600 --h 900 --wait 500
  แล้ว "เปิดดูภาพ" ทีละภาพ ประเมิน 5 หมวด ให้คะแนน 1-5 ต่อหมวด และเขียนปัญหาที่พบเป็นข้อ ๆ:
  1. ความถูกต้อง — object/ชื่อ/port/เวอร์ชัน/namespace ตรงกับ lab-outline ของแล็บนั้น · ลูกศรทิศถูก · ศัพท์ Kubernetes สะกดถูก · ไม่มี object ที่แล็บนั้นยังไม่ได้เรียน · ภาพทฤษฎี (d01-d08) สอนแนวคิดตามชื่อภาพได้จริงในภาพเดียว
  2. ตัวอักษร — สะกดผิดไทย/อังกฤษ · ขนาด ≥ 20px อ่านออกบนจอโปรเจกเตอร์ · ข้อความไม่ล้นกรอบ ไม่ทับเส้น/ขอบ/ลูกศร · ชื่อภาพอยู่บนสุด
  3. ตำแหน่งและเลย์เอาต์ — จัดแนวตรง ระยะห่างสม่ำเสมอ · ไม่มี element ตกขอบ · ไม่มีพื้นที่ว่างมหาศาล · ลูกศรไม่พาดผ่าน object/ข้อความ ไม่ไขว้กันโดยไม่จำเป็น · ชื่อโซน (namespace/node) ไม่ทับเส้นประของกรอบ
  4. ความสวยงาม — สีตาม palette ของชุด (acc #1c5cab · ok #116b11 · warn #86590a · crit #a32222 · ink #18181b · พื้น accw/okw/warnw/critw) · รูปทรงของ object ชนิดเดียวกันเหมือนกันทุกภาพ · เส้นหนาสม่ำเสมอ · องค์ประกอบสมดุล
  5. อื่น ๆ — ชื่อไฟล์ตรงรายการ · มีคู่ .excalidraw ที่เปิดได้ · SVG มี viewBox · ไม่มีชื่อคน/email จริง · ขนาดภาพเหมาะกับสไลด์ 16:9
