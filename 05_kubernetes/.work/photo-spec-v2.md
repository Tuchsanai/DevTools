# ภาพถ่ายสมจริง v2 — ต้องสื่อ "เนื้อหา Kubernetes" ของ section นั้นโดยตรง
(ผู้สอนสั่ง 2026-09-03: "ภาพจริงที่ใช้ ไม่ได้สื่อถึงเนื้อหาของ kubernetes เลย ให้ update ให้ตรงกับเนื้อหาของแต่ละ section")

## หลักการ (บังคับทุกภาพ)
1. ผู้ดูต้องบอกได้ใน 3 วินาทีว่าภาพนี้เกี่ยวกับ "ระบบคอมพิวเตอร์/container/cluster" และเกี่ยวกับหัวข้อไหน
   → ใช้ **คลังภาพของโลก Kubernetes** เท่านั้น ห้ามอุปมาสำนักงาน/ซองพัสดุ/ตู้เอกสาร/สะพาน/เคาน์เตอร์ ที่ไม่มีคอมพิวเตอร์อยู่ในภาพ
2. คลังภาพที่อนุญาต (เลือกให้ตรงหัวข้อ):
   - **ตู้คอนเทนเนอร์ (shipping container) · ท่าเรือ · เครนยกตู้ · เรือขนตู้** = container / Pod / orchestration / rolling update
     (สีตู้ใช้เป็นภาษา: **น้ำเงิน = เวอร์ชัน v1 · เขียวมรกต = v2** ตรงกับแอปในคอร์ส · ตู้ที่เสีย = สีซีด/บุบ)
   - **ห้อง data center สว่าง · แร็คเซิร์ฟเวอร์ · ไฟสถานะ LED (เขียว/เหลือง/แดง) · blade/สล็อต** = Node / cluster / Ready / อาการ
   - **สายเครือข่ายสีน้ำเงิน · patch panel · สวิตช์ · ไฟเบอร์ · กรงล็อก (colo cage)** = Service / NodePort / Ingress / request path
   - **ถาดไดรฟ์ hot-swap · storage array (disk shelf)** = emptyDir / PVC / stateful
   - **การ์ด/โมดูลสีเสียบหน้าเครื่อง · hardware security key · เครื่องอ่านบัตร** = ConfigMap / Secret
   - **ห้อง NOC · จอกราฟ (เส้น/แท่ง/บล็อกสี ไม่มีตัวอักษร) · มือบนคีย์บอร์ด** = kubectl / observability / อ่านอาการ
3. องค์ประกอบต้องมี "จุดโฟกัสเดียว" ที่เล่าแนวคิด (เช่น ตู้หนึ่งกำลังถูกเปลี่ยน · ไฟหนึ่งดวงเป็นแดง · สายหนึ่งเส้นไม่มีปลายทาง) ไม่ใช่ภาพห้องเครื่องทั่วไป
4. เหมือนเดิม: photorealistic · แสงสว่าง (ความสว่างเฉลี่ย grayscale ≥ 0.40 วัดด้วย Pillow) · **ห้ามตัวอักษร/ตัวเลข/โลโก้/ยี่ห้อ/ธง** ทุกที่ (จอ ป้าย ตู้ เสื้อ)
   · ห้ามใบหน้าคนชัด (ถ่ายจากหลัง/ไกล/เฉพาะมือ) · โทนสีสุภาพ accent น้ำเงิน เข้ากับสไลด์ · 16:9 · ส่งมอบ JPEG q88 1280×720 ≤ 350 KB
5. ทั้ง 15 ภาพของครั้งเดียวกันต้องเป็นสไตล์เดียวกัน (แสง/เลนส์/โทน) และภาพในครั้งเดียวกันต้องไม่ซ้ำองค์ประกอบกัน (ระบุ "มุมกว้าง" vs "close-up" ไว้แล้วด้านล่าง)
7. ภาพที่ใช้เต็มหน้า (cover-sN, labNNN-scene บนหน้าคั่นบท) ถูก gradient มืดบังครึ่งซ้าย ~58% → **จุดโฟกัสต้องอยู่ครึ่งขวาของภาพ** (ถ้าไม่ได้ ให้ปรับ object-position ของ <img> ในหน้านั้น) · ผิวตู้/เครน/เครื่องต้องเรียบ ไม่มี stencil/ป้าย/รอยขาวคล้ายอักษร (เพิ่ม 2026-09-03 หลังรอบตรวจ)
6. หลังเปลี่ยนภาพ ต้องแก้ข้อความในสไลด์ให้ตรงภาพใหม่: `alt` ของ `<img data-a="KEY">` ทุกภาพ · หน้าแนวคิด (concept) แก้ `<h2>ใช้ภาพจริงเป็นอุปมา — <em>…</em></h2>` และประโยค `<b>มองภาพนี้:</b> …` ให้เล่าภาพใหม่ · photos.md ให้ตรงภาพใหม่
