## Harness fixes
1. The job XML now carries `ParametersDefinitionProperty`, so `buildWithParameters` works before the first run. `build` requires HTTP 201 plus a `Location: …/queue/item/N` header, then polls the queue item (max 120 s, detects cancellation) and returns the real build number. `wait` is bounded (15 min) and `hub_build.sh` waits on that returned number.
2. **UTF-8:** `updatejob` POSTed `config.xml` as `application/xml` with no charset, so Jenkins decoded it as ISO-8859-1 and double-encoded all Thai text. It now sends `application/xml; charset=UTF-8`, and `config.xml` was verified to contain 0 mojibake sequences.
