สิ่งที่แก้ตามที่ขอ

  1. ขั้นที่ 1: เพิ่มคำอธิบายว่าทำไมใช้ 2 container แทน server 2 เครื่อง (jenkins คุม Pipeline และสั่งงานผ่าน SSH, devtools รับคำสั่งไปรัน, cicd-net ทำให้เรียกกันด้วยชื่อได้) และตัดบล็อก “ตรวจว่าทั้งสองตัว Up” ออก
  2. ขั้นที่ 2: แบ่งเป็นขั้นย่อย 2.1–2.6 พร้อมภาพ Setup Wizard 6 ภาพ (Unlock, plugins, installing, admin, Instance URL, ready) ภาพชุดนี้นำมาจาก LAB 1 และมีหมายเหตุไว้ใน README ว่าเป็นภาพที่นำกลับมาใช้ซ้ำ ถ้าเคยตั้งค่า Jenkins ไว้แล้ว ให้ login ด้วย admin เดิมแล้วข้ามไปขั้นที่ 3
  3. ขั้นที่ 3: อธิบายว่าทำไมยังต้องใช้ sshpass (Jenkins ต้อง SSH ไปหา devtools ด้วยรหัสผ่านจาก credential devtools-ssh แบบอัตโนมัติ) และติดตั้งผ่าน docker exec จาก host
  4. ขั้นที่ 5: เปลี่ยนเป็นขั้น “(ไม่บังคับ)” ข้ามได้ แล้วไปดูผลที่ stage Connect บนหน้าเว็บแทน
  5. เพิ่มภาพประกอบการสร้าง Docker Hub PAT (images/lab3_hub_pat_demo.png)
