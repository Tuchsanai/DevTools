LAB 3 — Jenkins Docker Build Push: ทดสอบและอัปเดตคู่มือเสร็จแล้ว

สวัสดีครับ งานตรวจ LAB 3 (04_Jenkins/001_Jenikin/003_LAB_Docker_Build_Push) เสร็จแล้วครับ สรุปดังนี้

สิ่งที่พบ

  • Jenkinsfile บน GitHub (commit a8d0c0b) ใช้ Build Now ครั้งแรกแล้วล้มที่ stage Test เพราะ build แรก Jenkins ยังไม่ส่งตัวแปร $APP_VERSION ให้ sh
  • แก้โดยเพิ่ม 2 บรรทัดใน environment (comment + APP_VERSION = "${params.APP_VERSION}")

ผลทดสอบบน Jenkins จริง

  • ไฟล์ฉบับแก้: build #1 (Build Now, 1.0.0) และ #2 (1.1.0) ผ่านครบ 6 stage + Post, push และ deploy สำเร็จ
  • หน้าร้านตรวจในเบราว์เซอร์แล้ว: กรองหมวดอาหารเปียกเหลือ 1 รายการ, ใส่ตะกร้าแล้วเป็น 1 ชิ้น / ฿329, Deployment info แสดง 1.1.0 build #2

README ที่อัปเดต

  • ข้อ 4.3 แสดง Jenkinsfile ทั้งไฟล์ ตรงกับไฟล์จริงทุกไบต์ พร้อมคำอธิบายภาษาไทย
  • ข้อ 5 เพิ่มคำอธิบายบั๊ก build แรก วิธีแก้ และเลข build ที่ควรเห็น
  • เปลี่ยนภาพเก่าเป็นภาพหน้าจอจริง: หน้า Stages, หน้าร้าน v1.0.0 / v1.1.0 และ Deployment info
  • เพิ่มข้อ 7: ภาพหน้าร้านทั้งหน้า + GIF พาชมร้าน (สร้างจากภาพหน้าจอจริง 5 ภาพ ภาพละ 2 วินาที)

⚠️ สิ่งที่ต้องทำต่อ

  • ยังไม่ได้ commit / push — GitHub main ยังเป็นไฟล์เดิม ไฟล์ฉบับแก้ทดสอบผ่าน Git repo จำลองในเครื่องเท่านั้น ต้อง push Jenkinsfile, README.md และภาพใหม่ใน images/ ก่อนให้นักศึกษาใช้
  • Docker Hub ยังมี tag ทดสอบ catfood-shop:lab3-1, lab3-2, lab3-3 ลบได้ถ้าไม่ต้องการ
