จบชุดนี้แล้วต้องทำให้เห็นได้ว่า…

  • แปลงคำบ่นของลูกค้าเป็น REQ/NFR ที่ทดสอบได้ แล้วชี้เทคนิค Docker ที่รับผิดชอบ
  • ยกฐานข้อมูลพร้อม schema + seed ด้วย docker run และอธิบายว่าข้อมูลหาย · รอด ตอนไหน
  • build image ของ backend และ frontend โดยเรียง Dockerfile ให้ layer cache ทำงาน
  • ใช้ multi-stage ตัด toolchain ออกจาก image (1.1GB → 298MB จาก source เดียวกัน)
  • แยกค่าตอน build (ARG) ออกจากค่าตอน run (ENV)
  • ต่อสามกล่องด้วยชื่อบน user-defined network และพิสูจน์ว่า db ไม่มีประตูออกนอกเครื่อง
  • ยุบ flag จาก 4 แล็บลง compose.yaml แล้วส่งมอบผ่าน Docker Hub โดยปลายทางไม่มี source
