# ใบงาน U-D7 — Integration ทั้งชุด

**สิทธิ์:** แก้ได้ทุกไฟล์ในชุด (unit เดียวที่มีสิทธิ์เขียน `Fullstack_App_Example.html` ตัวจริง)
**หน้าที่:** ประกอบของจาก U-D1…U-D4 · ปิด finding ที่เหลือ · ตัดสิน waiver · ยืนยันด้วยการรันจริง

## ลำดับ

```
python3 deck_build/build_deck.py                 # เขียนเด็คตัวจริง
python3 tools/ui/check_deck.py                   # งบต่อสไลด์ · fidelity · pointer · stale number · media
python3 tools/ui/check_numbers.py                # ตัวเลขข้ามไฟล์
python3 tools/ui/verify_slides.py --shots logs/shots_v3   # โครงนำทาง + ภาพทุกหน้าที่มีรูป
```
ทั้งสามตัวต้อง **exit 0**

## สิ่งที่ต้องตรวจด้วยตาที่สคริปต์ตรวจแทนไม่ได้

1. **หัวข้อกับเนื้อหาตรงกันทุกหน้า** — เปิด `logs/shots_v3/` ดูทีละใบ · เคยเจอ agent สลับ body ระหว่างสไลด์โดยหัวข้อยังถูก
2. **เรื่องเล่าต่อเนื่อง** — อ่านหัวข้อทั้งเด็คเรียงกัน ต้องยังเป็นเส้นเดียว: โจทย์ → ข้อกำหนด → ออกแบบ → LAB 1…5 → สรุป
3. **สไลด์ที่แตกออกมาต้องไม่ซ้ำเนื้อหากัน** และไม่มีหน้าที่เหลือแต่หัวข้อ
4. **`deck_build/COVERAGE.md`** — รวม `deck_build/changes/U-D*.md` ทุกไฟล์เข้าตารางเดียว
   ทุกแถวต้องมีปลายทางจริง · ถ้าแถวไหนบอก "ตัดทิ้ง" ต้องมีเหตุผลที่รับได้
5. **waiver** — ทุก `data-waiver` ต้องมีในทะเบียน · อนุมัติหรือปฏิเสธพร้อมเหตุผล · ที่ปฏิเสธต้องตีกลับให้แก้
6. **ป้าย eyebrow** — รัน `python3 tools/ui/check_deck.py --tags` ต้องผ่าน
7. **print** — `page.emulate_media(media="print")` แล้วตรวจว่าไม่มีหน้าไหนล้นกรอบ
