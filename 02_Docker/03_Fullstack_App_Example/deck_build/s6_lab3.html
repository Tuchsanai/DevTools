node_modules เหลือ 12 รายการ และ ไม่มี TypeScript

$ docker run --rm campusops-web:lab3 \
    sh -c 'ls node_modules | wc -l; ls -d node_modules/typescript'
12
ls: node_modules/typescript: No such file or directory

$ docker run --rm campusops-web:single \
    sh -c 'ls node_modules | wc -l; ls -d node_modules/typescript'
35
node_modules/typescript
คำสั่งแรกออก exit code 1 เป็นเรื่องปกติ — error คือคำตอบที่ถูกต้อง
คำตอบให้ลูกค้า: image ที่ส่งมอบไม่มี compiler ไม่มี devDependencies เหลือแต่ server.js กับ dependency ที่ Next รวมมาให้เท่าที่ใช้จริง

ARG ผูกกับ build · ENV ผูกกับ run

# ส่ง NEXT_PUBLIC_SITE_NAME ตอน run → <title>CampusOps · …</title> ไม่เปลี่ยน
$ docker build --build-arg NEXT_PUBLIC_SITE_NAME='ศูนย์ซ่อมบำรุง' …
<title>ศูนย์ซ่อมบำรุง · …</title>   # เปลี่ยนจริง เพราะถูกฝังตอน build
$ docker run -d -e API_BASE_URL=http://no-api-yet:8000 …
GET / -> HTTP 500 · [cause] getaddrinfo EAI_AGAIN no-api-yet
image ก้อนเดียวใช้ได้ทั้งเครื่อง dev และเครื่องลูกค้า — เปลี่ยนแค่ -e ตอนติดตั้ง · แต่ชื่อระบบบนหน้าเว็บต้อง build ใหม่เท่านั้น

ใครเป็น PID 1 ในกล่อง — 0.2 วินาที กับ 10.2 วินาที

docker stop ส่ง SIGTERM ให้ process หมายเลข 1 เท่านั้น แล้วรอ 10 วินาที ถ้ายังไม่จบจึงส่ง SIGKILL
exec form CMD ["node","server.js"]
$ docker exec ops-web-exec ps -o pid,args
PID   COMMAND
  1 next-server (v
$ time docker stop ops-web-exec
real	0m0.244s
shell form CMD node server.js; echo stopped
$ docker exec ops-web-shell ps -o pid,args
PID   COMMAND
  1 /bin/sh -c node server.js; echo stopped
  8 next-server (v
$ time docker stop ops-web-shell
real	0m10.281s
/bin/sh รับ SIGTERM แล้วไม่ส่งต่อให้ลูก Docker จึงรอครบ 10 วินาทีแล้วส่ง SIGKILL · exec form ให้ node รับสัญญาณตรง ๆ

กับดัก : Next.js 16 ไม่ได้ วางไฟล์ CSS ไว้ที่ .next/static/css

$ docker exec ops-web ls .next/static/chunks/*.css .next/static/css
.next/static/chunks/3sqcqigw583ti.css   # CSS อยู่ตรงนี้ · GET → 200 · 21048 ไบต์
ls: .next/static/css: No such file or directory
ต้อง COPY .next/static ทั้งก้อน — เจาะ .next/static/css ตามตำราเก่าจะ build ล้ม หรือได้หน้าเว็บที่ตอบ 200 ทุกหน้าแต่ไม่มีสีสักจุด
