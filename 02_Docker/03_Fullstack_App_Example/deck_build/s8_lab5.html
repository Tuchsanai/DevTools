compose.yaml คือ docker run ที่เขียนเป็นไฟล์

ของชิ้นเดียวที่ compose ให้เพิ่มมาจริง ๆ คือแถวล่างสุด (healthcheck: + depends_on: service_healthy) — ที่เหลือคือ flag เดิมจาก 4 แล็บที่แค่ย้ายบ้าน · network ไม่ต้องเขียนเพราะ compose สร้าง <project>_default ให้เอง

db เก็บข้อมูล · ตอบ healthcheck · ไม่เปิด ports

services:
  db:
    image: postgres:17-alpine
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./db/initdb:/docker-entrypoint-initdb.d:ro
    healthcheck:
      test: ["CMD-SHELL", "pg_isready …"]
      start_period: 30s
    # ไม่มี ports: — NFR-3 เขียนอยู่ตรงนี้

volume

pgdata ทำให้ข้อมูลรอดจากการลบกล่อง

healthcheck

pg_isready เป็นคำตอบว่า db พร้อมจริง

ไม่มี ports

ฐานข้อมูลไม่มีประตูจากเครื่อง host

api รอ db · web รอ api แล้วเปิดประตูเดียว

api:
  depends_on:
    db:
      condition: service_healthy
  …
web:
  ports:
    - "3000:3000"
  depends_on:
    api:
      condition: service_healthy
  …
ports: มีบรรทัดเดียวทั้งไฟล์ และอยู่ที่ web · ลำดับรอพร้อมคือ db → api → web

down รักษา 9 ใบ · down -v คืนเป็น seed 8 ใบ

down ปิดระบบตามปกติ
# เพิ่มใบแจ้งซ่อม → 9 ใบ
$ docker compose -p campusops down
local     campusops_pgdata
$ docker compose -p campusops up -d
$ … "SELECT count(*) FROM tickets;"
9  # ข้อมูลอยู่ครบ
down -v ล้าง volume
$ docker compose -p campusops down -v
 Volume campusops_pgdata Removed
(ว่างเปล่า)
$ docker compose -p campusops up -d
$ … "SELECT count(*) FROM tickets;"
8  # seed ตั้งต้นชุดใหม่
เลข 8 ไม่ใช่ข้อมูลเดิม แต่เป็น seed ที่ init script ใส่ใหม่เมื่อ volume ว่าง · transcript เต็มอยู่ที่ 005_LAB_Compose_And_Ship/readme.md · การทดลองที่ 6

ส่งมอบให้ลูกค้า = ส่ง image ไม่ใช่ส่งซอร์สโค้ด

$ docker login -u <DOCKER_USER> → Login Succeeded
$ docker tag campusops-api:latest <DOCKER_USER>/campusops-api:1.0
$ docker push <DOCKER_USER>/campusops-api:1.0 → manifest list: sha256:70b4a206b898…
# ทำตัวเป็นเครื่องลูกค้า : ลบ image ทิ้ง → pull → ห้าม build
$ docker compose -p campusops up -d --no-build → GET / -> 200
--no-build พิสูจน์ว่าเครื่องนี้ไม่ได้แตะซอร์สโค้ดเลย — ลูกค้าใช้ image จาก Docker Hub + compose.yaml + db/initdb/ · ไม่ต้องมี Node หรือ Python
